6
Re-register Members
15-30 min
Option A: Re-add manually via the app
Use the + button to add each member. Tedious but clean.
Option B: Bulk upload via the Sheet directly
If you have a member list (spreadsheet, text, screenshot), paste directly into the Members tab. Format: one row per member, follow the column headers exactly. ID format: MEM-001, MEM-002, etc.
Option C: Export from local device
If the admin device still has members in local IndexedDB (from before lockout), go to Settings > Data > Export CSV. This gives you all members. Paste into the new Sheet.
7

5 min per device
Each device needs the new script URL
Settings > Connection > Edit URL > paste new URL
Or: clear app data and re-setup
If device still has old URL cached, clear site data in browser settings for the FlockTrack URL, then re-open and enter new script URL
Preventing Future Lockouts
  • Use the new account occasionally for normal email/browsing (not just API)
  • Add a recovery email from a different account
  • Enable 2FA once the account is stable (after a few days)
  • Consider sharing the Sheet with your personal Gmail as backup editor
  • Monthly backups are already built into the script (runs automatically)
